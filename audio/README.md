# 音乐资源目录规范

把音乐文件放进本目录，按以下命名（支持 `.mp3` / `.ogg` / `.wav`）。缺自动静音，无破坏。

## 文件清单

| 文件 | 用途 |
|---|---|
| `menu.mp3` 或 `menu.ogg` 等 | **主界面音乐**（主菜单/选关/商店/存档界面） |
| `theme1.mp3` | **地图主题1**（第 1~11 关，森林） |
| `theme2.mp3` | **地图主题2**（第 12~23 关，深林） |
| `theme3.mp3` | **地图主题3**（第 24~39 关，沙漠） |
| `theme4.mp3` | **地图主题4**（第 40~47 关，火山） |
| `theme5.mp3` | **地图主题5**（第 48~50 关，水晶/终局） |

## 主题分段规则（与美术套图一致）
- 1~11 关 → `theme1`
- 12~23 关 → `theme2`
- 24~39 关 → `theme3`
- 40~47 关 → `theme4`
- 48~50 关 → `theme5`

## 说明
- 音乐在进入对应界面/关卡时**循环播放**
- 同类界面（主菜单/选关/商店/存档）共用 `menu`
- 缺某个音乐文件 → 该处静音，不影响其它
- 循环播放由浏览器 Audio 对象实现，首次需用户点击/交互后才开始（浏览器自动播放限制）
