# 生肖英雄 · UI 贴图生成 Prompt（美术风格参考主界面UI）

> 用途：把这些提示词喂给 AI 出图工具，逐张生成 UI 组件贴图，覆盖 `images/UI/<子目录>/` 同名文件即可生效（缺图自动回退现有样式）。

## 一、全局美术风格（每段 Prompt 开头都带上）

**游戏名**：十二生肖 · 骰子爬塔（主界面 UI 同款低多边形卡通风）

- **风格**：低多边形 3D 卡通（low-poly / clay render），轻微手绘卡通。
- **配色**：暖金色 / 米黄 / 赭棕木质 + 鎏金描边 + 朱红点缀（参考主界面UI：木牌、金边、暖木按钮、红绸带）。
- **质感**：光滑渐变 + 细金描边 + 柔和投影；按钮下缘 3px 金色厚边（似可按压的浮雕）；浅色高光让元件更立体。
- **构图**：组件居中、四边留安全边距；**背景透明**（PNG 透明底，非合成图）。图形铺满整张画布（因游戏会拉伸平铺，**不要留透明边距**，除小图标外）。
- **文字**：**不要在素材上写字**——文字/数字由游戏叠加，素材只画底板/图标/纹理。
- **点缀**：可用小骰子、祥云、生肖动物小装饰呼应主题，但保持组件主体简洁。
- **格式**：透明背景 PNG；分辨率按下方"建议画布(2x)"给出（游戏内会缩放显示）。
